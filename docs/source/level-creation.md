# Levels Creation

## How to Add Levels

1. Open the Level Editor from **FANNΞC > Rail Express > Level Editor**.
2. Select the **Levels** tab.
3. Scroll to the bottom of the list and press **+** to add a new level.
4. Set the level's grid size using the **X** and **Y** fields.
5. Click a grid element icon — Rail, Stopper, Curve, Train, Coin, or Environment — in the palette,
   then click a cell on the grid to place it. Click a placed element again to remove it, or drag
   it to a new cell to move it. Right-click a placed element to rotate it.

## Developer Panel

The Developer Panel lets you jump between levels while the game is running, without restarting
Play mode for every test.

1. Turn it on from **FANNΞC > Rail Express > Actions > Show Developer Panel**.
2. Press **Play**. A row of buttons appears at the bottom of the screen — use them to switch
   directly to any level while playtesting.
